# Meteor and Atmospheric Data Analysis - Study References

**Language:** English | Português

---

## English

Central repository for organizing references, data parsing workflows, filtering scripts, and scientific visualization for meteor physics and atmospheric radar research.

### Useful Repositories & References

* **Python Data Science Handbook (Jake VanderPlas):** Focused on data manipulation with Pandas and visualization with Matplotlib.
  * [GitHub Repository](https://github.com/jakevdp/PythonDataScienceHandbook) | [Online Book Version](https://jakevdp.github.io/PythonDataScienceHandbook/)

* **Project Pythia Foundations:** Scientific Python tutorials tailored for geosciences and atmospheric data.
  * [GitHub Repository](https://github.com/ProjectPythia/pythia-foundations) | [Online Version](https://foundations.projectpythia.org/)

* **Kaggle:** Platform featuring beginner-friendly programming courses, data analysis tutorials, and datasets to practice coding skills.
  * [Kaggle Platform](https://www.kaggle.com/)
      
* **GMN Python API:** Reference code for structuring data reading, filtering, and handling meteor data in DataFrames.
  * [GitHub Repository](https://github.com/rickybassom/gmn-python-api)

* **WesternMeteorPyLib (WMPL):** Advanced Python library for meteor physics, trajectory calculations, and scientific I/O.
  * [GitHub Repository](https://github.com/wmpg/WesternMeteorPyLib)

* **RPi Meteor Station (RMS):** Utility scripts for batch processing directories and plotting temporal/spatial distributions.
  * [GitHub Repository](https://github.com/CroatianMeteorNetwork/RMS)

* **Space Physics Organization:** Open-source tools for radar data parsing and atmospheric models.
  * [GitHub Organization](https://github.com/space-physics)

## Português

Repositório central para organizar referências, fluxos de leitura de dados (parsing), scripts de filtragem e visualização científica para a pesquisa de física de meteoros e radares atmosféricos.

### Repositórios Úteis e Referências

* **Python Data Science Handbook (Jake VanderPlas):** Focado em manipulação de dados com Pandas e visualização com Matplotlib.
  * [Repositório no GitHub](https://github.com/jakevdp/PythonDataScienceHandbook) | [Versão Livro Online](https://jakevdp.github.io/PythonDataScienceHandbook/)

* **Project Pythia Foundations:** Tutoriais de Python científico voltados para geociências e dados atmosféricos.
  * [Repositório no GitHub](https://github.com/ProjectPythia/pythia-foundations) | [Versão Online](https://foundations.projectpythia.org/)
 
* **Kaggle:** Plataforma com cursos práticos de programação para iniciantes, tutoriais de análise de dados e bases para praticar.
  * [Plataforma Kaggle](https://www.kaggle.com/)

* **GMN Python API:** Código de referência para estruturação de leitura, filtragem e manipulação de dados de meteoros em DataFrames.
  * [Repositório no GitHub](https://github.com/rickybassom/gmn-python-api)

* **WesternMeteorPyLib (WMPL):** Biblioteca avançada em Python para física de meteoros, cálculos de trajetória e I/O científico.
  * [Repositório no GitHub](https://github.com/wmpg/WesternMeteorPyLib)

* **RPi Meteor Station (RMS):** Scripts utilitários para processamento em lote de diretórios e plotagem de distribuições temporais e espaciais.
  * [Repositório no GitHub](https://github.com/CroatianMeteorNetwork/RMS)

* **Space Physics Organization:** Ferramentas de código aberto para leitura de dados de radar e modelos atmosféricos.
  * [Organização no GitHub](https://github.com/space-physics)
